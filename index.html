Tennis Lab Backups

A private backup utility for the owner's Tennis Lab application. It creates encrypted recovery archives in a dedicated private Google Drive folder.

Google access is limited to files created or explicitly opened with this utility, using the drive.file permission. The utility does not request access to every file in Google Drive.

Backup contents are encrypted on the owner's server before upload. Only the newest successfully verified archive is retained; older matching archives in the dedicated folder are permanently deleted after verification.

This utility has no public sign-up, advertising, analytics, or sale of user data. It is operated for the owner's application recovery.
